How to run any process on this page

  1. Open the process folder. Local: .... Backup copy (any PC): .... One folder per process.
  2. Read README.txt first. One screen: what the process does, when it runs, how to run it, and the LAST VERIFIED date.
  3. Run it. Scripted processes: double-click run.bat. Manual processes: follow SOP.txt step by step. Each run writes a line to last-run.log, which this page reads.
  4. Or ask Claude Code. Open Claude Code in C:\Users\john.slagboom and type the trigger phrase shown in the row. Claude reads the SOP folder and runs it; it does not re-derive the process.
New laptop or nothing here works? Follow .... The SOP folders and the Claude configuration are both backed up on the shared drive; nothing depends on one PC or one person.
